# Controles de GeoDrone

## Pilotaje

| Entrada | Acción |
|---|---|
| W/A/S/D | Avanzar, izquierda, retroceder, derecha respecto a cámara |
| Flechas | Equivalentes a W/A/S/D |
| Espacio | Ascender |
| Shift izquierdo/derecho | Descender |
| Arrastre izquierdo | Rotar cámara |
| Rueda | Acercar/alejar |
| F | Recentrar seguimiento |

## Vistas y HUD

| Tecla | Acción |
|---|---|
| C | Orbital → seguimiento → superior |
| V | Rotar seis modos de terreno |
| M | Minimapa |
| H | Curvas de nivel |
| L | Ruta al objetivo |
| F1 | Ayuda de controles |
| F3 | Estadísticas |

## Misión y mapas

| Tecla | Acción |
|---|---|
| R | Reiniciar misión actual |
| Tab / Backspace | Mapa siguiente / anterior |
| 1…9 | Selección directa |
| F5 / F9 | Guardar / recuperar máscara y dron |
| Esc o P | Pausar |

Para escanear, mantén el dron dentro del anillo, entre 1,5 y 28 unidades sobre la zona y con rapidez inferior a 14. El arco cian muestra avance; al salir, baja gradualmente.

## Medición

1. Pulsa `X`.
2. Clic izquierdo sobre el terreno para añadir puntos.
3. Dos puntos producen distancia, desnivel, pendiente y ángulo.
4. Tres o más producen área proyectada.
5. Clic derecho limpia.
6. `X` vuelve a pilotaje normal.

Mientras el modo está activo, el clic izquierdo selecciona y no orbita.

## Menús

En inicio/pausa usa W/S o flechas y Enter. En configuración, izquierda/derecha cambia valores. Esc vuelve al nivel anterior o reanuda. El resumen final admite Enter para seguir, R para reiniciar y Tab para cambiar mapa.
